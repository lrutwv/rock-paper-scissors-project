Rock Paper Scissors

A fun Human VS Robot Rock Paper Scissors game built with HTML, CSS, and JavaScript.

Theme

The website has a retro Y2K / Frutiger Aero-inspired theme with ocean, summer, and early-2000s web aesthetics. It uses bright colors, playful graphics, pixel-style elements, and a nostalgic game-like interface.

 What I Learned

Through this project, I practiced:

HTML structure and semantic elements
CSS styling, Flexbox, animations, and responsiveness
JavaScript functions, arrays, conditionals, and DOM manipulation
Event listeners and game logic
Score and round tracking
Git and GitHub for version control
